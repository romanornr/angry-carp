# Define when a case begins

Type: grilling
Labels: wayfinder:grilling
Status: resolved
Assignee: operator with planning agent
Parent: ../map.md
Blocked by: none

## Question

Does acquiring an email create an investigation case, or does a case begin only when a concrete phishing concern needs investigation? Resolve the distinction with an ordinary message and a suspicious message before choosing data structures.

## Context

The operator requested a restart from the agreed requirements after the first importer introduced unreviewed data structures and commands. The importer is withdrawn. Agent-guided use is primary, with direct terminal operation also supported. Existing capability experiments do not determine the new domain model.

## Resolution

The operator answered no: acquiring an ordinary email does not create a case. Acquisition and investigation remain distinct. The glossary records this boundary. This answer does not settle the precise investigation trigger, ordinary-mail retention, message identity, or acquisition progress.
